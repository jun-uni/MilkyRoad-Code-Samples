# ID 기반 투사체 오브젝트 풀

함선 무기가 사용하는 투사체를 종류별로 미리 생성하고, 발사와 반환 과정에서 같은 인스턴스를 재사용하는 시스템입니다.

## 처리 흐름

1. `ProjectileData`에 ID, 프리팹, 속도, 수명, 이동 방식을 설정합니다.
2. `ProjectileManager`가 유효한 ID별 큐를 만들고 투사체를 미리 생성합니다.
3. 발사 시 해당 ID의 큐에서 투사체를 꺼내 활성 목록으로 이동합니다.
4. 큐가 비면 필요한 종류의 투사체만 추가 생성합니다.
5. 투사체가 목표에 도달하거나 수명이 끝나면 상태를 초기화하고 기존 큐로 반환합니다.

## 주요 코드

### [`ProjectileManager.cs`](ProjectileManager.cs)

ID별 데이터, 반환 큐, 계층 부모를 `PoolEntry`로 묶어 관리합니다. 초기화 단계에서 중복 ID, 잘못된 프리팹, 유효하지 않은 이동 설정을 거르고 존재하지 않는 ID 요청은 예외 없이 실패로 반환합니다. 반환 위치는 저장된 Transform을 사용하므로 Hierarchy를 이름으로 다시 탐색하지 않습니다.

### [`MyProjectile.cs`](MyProjectile.cs)

발사 중인 투사체의 수명과 이동만 갱신합니다. 직선 구간은 `MoveTowards`로 목표를 지나치지 않게 이동하고, 곡선 구간은 2차 베지어 좌표로 계산합니다. 타격 콜백의 성공 여부와 관계없이 풀에 복귀하며, 재사용 전에 이전 궤적과 콜백 상태를 초기화합니다.

### [`ProjectileData.cs`](ProjectileData.cs)

투사체 식별 정보와 이동 설정을 직렬화해 프리팹, 속도, 수명, 곡선 전환 시점을 데이터로 교체할 수 있습니다.

## 설계 요점

- 투사체 ID를 키로 사용하는 상수 시간 풀 조회
- 초기 생성과 부족한 풀의 동적 확장
- 중복 ID·누락 프리팹·잘못된 컴포넌트 검증
- 활성 투사체와 대기 투사체의 명확한 상태 전환
- 투사체에서 풀 반환 책임을 분리하는 콜백
